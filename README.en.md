This is a vocabulary learning tool built for "extreme learning efficiency," integrating the core **SRS (Spaced Repetition System)** algorithm from Anki. Through precise scheduling and visual aids, it helps you efficiently transform short-term memory into long-term mastery.

> **"Smart is the New Sexy. Make learning elegant, efficient, and frictionless."**

---

## ✨ Core Features

*   📦 **Single-File Execution**: No environment setup required. Simply download `index.html` and open it in any browser.
*   🧠 **SRS Algorithm**: Built-in `Again`, `Hard`, `Good`, and `Easy` grading mechanisms that automatically adjust review intervals.
*   🖼️ **Dynamic Visual Association**: Integrated with LoremFlickr API to fetch relevant images based on vocabulary context, featuring "background pre-loading" for instant display.
*   🔊 **Audio Pronunciation**: Supports US-English text-to-speech for both words and example sentences to reinforce auditory memory.
*   💾 **Auto-Save Progress**: Utilizes LocalStorage to save learning progress in real-time, allowing you to pick up right where you left off.
*   📱 **iPhone Optimized**: Tailored UI proportions for mobile devices with support for a full-screen "Add to Home Screen" experience.

## 📱 iPhone Quick Start

For the best experience, it is recommended to add this web app to your home screen:

1.  Open your GitHub Pages link in **Safari** on your iPhone.
2.  Tap the **"Share"** button (square with an upward arrow) at the bottom.
3.  Select **"Add to Home Screen"**.
4.  Now you can launch your Flashcard Cabin anytime, just like a native app!

## ⌨️ Keyboard Hotkeys

If you are using this on a computer, you can use the following hotkeys for efficient review:

| Key | Action | Description |
| :--- | :--- | :--- |
| **Space** | Flip Card | Show the answer and image |
| **Enter** | Pronounce | Replay the current word or sentence |
| **1** | **Again** | Review again in < 1 minute |
| **2** | **Hard** | Insert into the middle of the remaining queue |
| **3** | **Good** | Move to the end of the current session |
| **4** | **Easy** | Graduate the card (Learning completed) |
